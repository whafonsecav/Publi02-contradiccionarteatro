# Contra el dicho · Relatos Intensos 2027

Campaña para **Relatos Intensos para Mentes Traviesas**, el show de monólogos de Contradicción Arteatro.
Parcial final de Publicidad 2 (Corte 3) · Politécnico Grancolombiano.

- **Presentación:** abre `index.html` (o la página publicada de este repositorio).
- **Teclas:** → siguiente · ← anterior · F pantalla completa · M índice. En celular: toca o desliza.
- **Piezas:** `assets/piezas/` (Key Visual maestro y uno por pilar) y `assets/video/` (video 9:16).

Concepto creativo: **Contra el dicho** · Titular: «De eso ~~no~~ sí se habla» · Eslogan: «Alguien tenía que decirlo».

Rostros, flores y fondos generados con IA; voces clonadas con permiso. Las reseñas y puntajes son ejemplos de formato.
